Below is a production-safe implementation blueprint. It is intentionally **dry-run-first**, requires an explicit approval manifest for destructive actions, and does not assume that the 969 records are actually duplicates. The supplied IP address should be treated as an origin address only; do not expose MariaDB directly to the Internet.

## 0. Mandatory execution controls

Before any remediation:

```bash
# Run from a bastion or the WordPress host, never from a developer laptop.
export WP_ROOT=/var/www/helmetsan.com
export RUN_ID="$(date -u +%Y%m%dT%H%M%SZ)"

cd "$WP_ROOT"

wp core is-installed
wp db check
wp option get siteurl
wp plugin is-active polylang
wp plugin is-active wordpress-seo

# Backups
mkdir -p "/var/backups/helmetsan/$RUN_ID"

wp db export \
  "/var/backups/helmetsan/$RUN_ID/pre-remediation.sql" \
  --add-drop-table

tar -C "$WP_ROOT" \
  -czf "/var/backups/helmetsan/$RUN_ID/wp-content.tar.gz" \
  wp-content

# Ensure the backup is readable and non-empty.
test -s "/var/backups/helmetsan/$RUN_ID/pre-remediation.sql"
test -s "/var/backups/helmetsan/$RUN_ID/wp-content.tar.gz"

# Put the site into a maintenance/read-only operating mode if available.
wp maintenance-mode activate
```

Do not perform deletion based only on language, title similarity, or URL similarity. A duplicate must have a deterministic canonical record and a human- or rule-approved evidence source.

# Context 1 — orphan cleanup and translation healing

## 1.1 Data model

Use an approval manifest generated by a read-only classifier:

```json
[
  {
    "post_id": 12345,
    "class": "A",
    "canonical_id": 12001,
    "reason": "same SKU and normalized manufacturer part number",
    "confidence": 0.998,
    "redirect": "/helmets/example-canonical/"
  },
  {
    "post_id": 12346,
    "class": "B",
    "translation_ids": {
      "en": 12000,
      "fr": 12346
    },
    "reason": "same SKU; translated content fingerprints agree",
    "confidence": 0.994
  },
  {
    "post_id": 12347,
    "class": "C",
    "reason": "unique SKU and valid product data"
  },
  {
    "post_id": 12348,
    "class": "D",
    "reason": "placeholder title and no product identifiers"
  }
]
```

The classifier should write candidates separately from the approval manifest:

```text
/tmp/helmetsan-orphans-candidates.json
/tmp/helmetsan-orphans-approved.json
```

Only the approved file may be used for mutation.

## 1.2 Lease table

The lease table prevents two workers from processing the same post. It uses WordPress's database connection for MariaDB. The SQLite adapter should be implemented only if the site actually runs on SQLite; standard WordPress production installations generally do not.

Create `wp-content/mu-plugins/helmetsan-remediation-lease.php`:

```php
<?php
/**
 * Plugin Name: Helmetsan Remediation Lease
 */

defined('ABSPATH') || exit;

function hs_remediation_lease_table(): string {
    global $wpdb;
    return $wpdb->prefix . 'hs_remediation_leases';
}

function hs_remediation_install_lease_table(): void {
    global $wpdb;

    $table = hs_remediation_lease_table();
    $charset = $wpdb->get_charset_collate();

    require_once ABSPATH . 'wp-admin/includes/upgrade.php';

    dbDelta(
        "CREATE TABLE {$table} (
            object_type varchar(32) NOT NULL,
            object_id bigint(20) unsigned NOT NULL,
            run_id varchar(64) NOT NULL,
            lease_token char(64) NOT NULL,
            leased_until datetime NOT NULL,
            status varchar(16) NOT NULL DEFAULT 'leased',
            PRIMARY KEY (object_type, object_id),
            KEY leased_until (leased_until),
            KEY run_id (run_id)
        ) {$charset};"
    );
}

function hs_remediation_acquire_lease(
    string $object_type,
    int $object_id,
    string $run_id,
    int $seconds = 900
): ?string {
    global $wpdb;

    $table = hs_remediation_lease_table();
    $token = bin2hex(random_bytes(32));
    $until = gmdate('Y-m-d H:i:s', time() + $seconds);

    /*
     * This is lease bookkeeping, not content deletion. Content must still be
     * changed through WordPress APIs.
     */
    $sql = $wpdb->prepare(
        "INSERT INTO {$table}
            (object_type, object_id, run_id, lease_token, leased_until, status)
         VALUES (%s, %d, %s, %s, %s, 'leased')
         ON DUPLICATE KEY UPDATE
            run_id = IF(leased_until < UTC_TIMESTAMP(), VALUES(run_id), run_id),
            lease_token = IF(leased_until < UTC_TIMESTAMP(), VALUES(lease_token), lease_token),
            leased_until = IF(leased_until < UTC_TIMESTAMP(), VALUES(leased_until), leased_until),
            status = IF(leased_until < UTC_TIMESTAMP(), 'leased', status)",
        $object_type,
        $object_id,
        $run_id,
        $token,
        $until
    );

    $wpdb->query($sql);

    $owned = $wpdb->get_var(
        $wpdb->prepare(
            "SELECT lease_token
             FROM {$table}
             WHERE object_type = %s
               AND object_id = %d
               AND run_id = %s
               AND leased_until >= UTC_TIMESTAMP()
               AND status = 'leased'",
            $object_type,
            $object_id,
            $run_id
        )
    );

    return hash_equals((string) $token, (string) $owned) ? $token : null;
}

function hs_remediation_release_lease(
    string $object_type,
    int $object_id,
    string $run_id,
    string $token,
    string $status = 'done'
): void {
    global $wpdb;

    $table = hs_remediation_lease_table();

    $wpdb->query(
        $wpdb->prepare(
            "UPDATE {$table}
             SET status = %s
             WHERE object_type = %s
               AND object_id = %d
               AND run_id = %s
               AND lease_token = %s",
            $status,
            $object_type,
            $object_id,
            $run_id,
            $token
        )
    );
}
```

Activate once:

```bash
wp eval 'hs_remediation_install_lease_table();'
```

## 1.3 `classify_and_remediate_orphans.php`

Place this in `wp-content/mu-plugins/` or execute it with WP-CLI so WordPress and Polylang are loaded.

```php
<?php
/**
 * Usage:
 * wp eval-file classify_and_remediate_orphans.php \
 *   --input=/tmp/helmetsan-orphans-approved.json \
 *   --run-id=20250101T000000Z \
 *   --apply=0
 *
 * Deletion is impossible unless --apply=1.
 */

defined('ABSPATH') || exit;

if (!defined('WP_CLI') || !WP_CLI) {
    fwrite(STDERR, "This script must run through WP-CLI.\n");
    exit(1);
}

$opts = getopt('', [
    'input:',
    'run-id:',
    'apply::',
    'log::',
]);

$input = $opts['input'] ?? '';
$runId = $opts['run-id'] ?? gmdate('Ymd\THis\Z');
$apply = filter_var($opts['apply'] ?? false, FILTER_VALIDATE_BOOLEAN);
$logPath = $opts['log'] ?? WP_CONTENT_DIR . "/uploads/helmetsan-remediation-{$runId}.jsonl";

if (!$input || !is_readable($input)) {
    WP_CLI::error("Readable --input manifest is required.");
}

$items = json_decode(file_get_contents($input), true, 512, JSON_THROW_ON_ERROR);

if (!is_array($items)) {
    WP_CLI::error("Manifest must be a JSON array.");
}

$log = static function (array $event) use ($logPath): void {
    $event['time'] = gmdate('c');
    file_put_contents(
        $logPath,
        wp_json_encode($event, JSON_UNESCAPED_SLASHES) . PHP_EOL,
        FILE_APPEND | LOCK_EX
    );
};

$normalize_url = static function (string $url): string {
    $url = esc_url_raw($url);
    $parts = wp_parse_url($url);

    if (!$parts || empty($parts['path'])) {
        return '';
    }

    return trailingslashit($parts['path']);
};

$save_translations = static function (array $translations): void {
    /*
     * Public Polylang API where available.
     */
    if (function_exists('pll_save_post_translations')) {
        pll_save_post_translations($translations);
        return;
    }

    /*
     * Required by the requested deployment specification, but guarded because
     * PLL()->model is an internal API and varies between Polylang releases.
     */
    if (
        function_exists('PLL') &&
        PLL() &&
        isset(PLL()->model->post) &&
        method_exists(PLL()->model->post, 'save_translations')
    ) {
        PLL()->model->post->save_translations($translations);
        return;
    }

    throw new RuntimeException(
        'No supported Polylang translation-save API was found.'
    );
};

foreach ($items as $item) {
    $postId = absint($item['post_id'] ?? 0);
    $class = strtoupper((string) ($item['class'] ?? ''));

    if (!$postId || !in_array($class, ['A', 'B', 'C', 'D'], true)) {
        $log([
            'event' => 'invalid_manifest_item',
            'item' => $item,
        ]);
        continue;
    }

    $token = hs_remediation_acquire_lease('post', $postId, $runId);

    if (!$token) {
        $log([
            'event' => 'lease_skipped',
            'post_id' => $postId,
            'class' => $class,
        ]);
        continue;
    }

    try {
        $post = get_post($postId);

        if (!$post) {
            throw new RuntimeException('Post does not exist.');
        }

        if ($post->post_status !== 'publish') {
            throw new RuntimeException('Post is not published.');
        }

        if ($class === 'A') {
            $canonicalId = absint($item['canonical_id'] ?? 0);
            $redirect = $normalize_url((string) ($item['redirect'] ?? ''));

            if (!$canonicalId || $canonicalId === $postId || !$redirect) {
                throw new RuntimeException(
                    'Class A requires canonical_id and a valid redirect path.'
                );
            }

            $canonical = get_post($canonicalId);

            if (!$canonical || $canonical->post_status !== 'publish') {
                throw new RuntimeException('Canonical post is invalid.');
            }

            if (!$apply) {
                $log([
                    'event' => 'dry_run_duplicate',
                    'post_id' => $postId,
                    'canonical_id' => $canonicalId,
                    'redirect' => $redirect,
                ]);
                hs_remediation_release_lease('post', $postId, $runId, $token, 'dry-run');
                continue;
            }

            /*
             * Store redirect before deletion. The redirect resolver should read
             * this post meta or a dedicated redirect CPT.
             */
            $redirectId = wp_insert_post([
                'post_type' => 'hs_redirect',
                'post_status' => 'publish',
                'post_title' => "Redirect {$postId} to {$canonicalId}",
                'meta_input' => [
                    '_hs_redirect_source_post_id' => $postId,
                    '_hs_redirect_source_path' => wp_parse_url(
                        get_permalink($postId),
                        PHP_URL_PATH
                    ),
                    '_hs_redirect_target_path' => $redirect,
                    '_hs_redirect_status' => 301,
                ],
            ], true);

            if (is_wp_error($redirectId)) {
                throw new RuntimeException($redirectId->get_error_message());
            }

            /*
             * wp_delete_post() invokes WordPress cleanup, including post
             * relationships and term-count maintenance. No SQL DELETE is used.
             */
            $deleted = wp_delete_post($postId, true);

            if (!$deleted) {
                throw new RuntimeException('wp_delete_post() failed.');
            }

            $log([
                'event' => 'duplicate_deleted',
                'post_id' => $postId,
                'canonical_id' => $canonicalId,
                'redirect_id' => $redirectId,
            ]);

            hs_remediation_release_lease('post', $postId, $runId, $token, 'done');
            continue;
        }

        if ($class === 'B') {
            $translations = [];

            foreach (($item['translation_ids'] ?? []) as $lang => $translationId) {
                $translationId = absint($translationId);

                if (!$translationId || !get_post($translationId)) {
                    throw new RuntimeException("Invalid translation for {$lang}.");
                }

                $translations[sanitize_key($lang)] = $translationId;
            }

            if (count($translations) < 2) {
                throw new RuntimeException('Class B requires at least two translations.');
            }

            if (!$apply) {
                $log([
                    'event' => 'dry_run_translation_cluster',
                    'post_id' => $postId,
                    'translations' => $translations,
                ]);
                hs_remediation_release_lease('post', $postId, $runId, $token, 'dry-run');
                continue;
            }

            $save_translations($translations);

            $log([
                'event' => 'translation_cluster_saved',
                'post_id' => $postId,
                'translations' => $translations,
            ]);

            hs_remediation_release_lease('post', $postId, $runId, $token, 'done');
            continue;
        }

        if ($class === 'C') {
            $queueId = wp_insert_post([
                'post_type' => 'hs_translation_job',
                'post_status' => 'publish',
                'post_title' => "Translation job for {$postId}",
                'meta_input' => [
                    '_hs_source_post_id' => $postId,
                    '_hs_source_language' => function_exists('pll_get_post_language')
                        ? pll_get_post_language($postId)
                        : '',
                    '_hs_job_status' => 'queued',
                    '_hs_job_created_at' => gmdate('c'),
                ],
            ], true);

            if (is_wp_error($queueId)) {
                throw new RuntimeException($queueId->get_error_message());
            }

            $log([
                'event' => 'translation_job_queued',
                'post_id' => $postId,
                'job_id' => $queueId,
                'applied' => $apply,
            ]);

            hs_remediation_release_lease('post', $postId, $runId, $token, 'queued');
            continue;
        }

        if ($class === 'D') {
            /*
             * Never delete corrupt records immediately. Mark them 410 and
             * preserve them for audit/recovery.
             */
            update_post_meta($postId, '_hs_http_status', 410);
            update_post_meta($postId, '_hs_remediation_class', 'D');
            update_post_meta($postId, '_hs_remediation_run', $runId);

            if ($apply) {
                wp_update_post([
                    'ID' => $postId,
                    'post_status' => 'draft',
                ]);
            }

            $log([
                'event' => 'corrupt_marked_410',
                'post_id' => $postId,
                'drafted' => $apply,
            ]);

            hs_remediation_release_lease('post', $postId, $runId
